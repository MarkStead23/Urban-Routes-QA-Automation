# Urban Routes — Automated UI Testing

## Project Overview
This project demonstrates automated UI testing of the Urban Routes web application, completed during my TripleTen Quality Assurance training.

## Technologies Used
- Python
- Selenium WebDriver
- PyCharm
- Git and GitHub

## Automated Test Scenarios
1. Set pickup and destination addresses
2. Select the Supportive ride plan
3. Enter and confirm a phone number
4. Add a payment card
5. Enter a comment for the driver
6. Select blanket and handkerchiefs
7. Add two ice creams
8. Verify the car-search modal appears

## Project Organization
- `main.py` — Automated test cases
- `pages.py` — Page Object Model methods
- `data.py` — Test data
- `helpers.py` — Training-provided helper functions
